# Altera HR Analysis

## Introduction  
This dashboard serves as a decision-support tool highlighting key HR metrics and performance indicators.

## Aim  
To develop a simple HR Analytics Dashboard that provides insightful reports on the organization’s workforce.

## Data Source  
Kaggle dataset: `Altera_Emp_Data.xlsx`
